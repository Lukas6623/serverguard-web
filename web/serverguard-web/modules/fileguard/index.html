FileGuard

Защита важных файлов сервера

Модуль в разработке

FileGuard появится здесь, когда на сервере будет реализован соответствующий бэкенд-модуль. Раздел уже подключён к общей навигации ServerGuard и активируется автоматически, как только сервер начнёт отвечать fileguard: true на /api/modules.
